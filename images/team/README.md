# Team photos

One photo per teammate, as WebP (e.g. `eshan.webp`). In `index.html`, that
person's panel points to it with `data-photo="images/team/eshan.webp"`.

To add or swap a photo, crop it to a tall portrait (3 wide by 5 high, about
600 x 1000 px) with the face in the top half, then save it here. If the face
isn't in the middle across, set `--px` on that person's panel (see the main
README). Their panel colour is blended over the photo.
